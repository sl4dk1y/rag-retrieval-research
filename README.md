# RAG Retrieval Research

Студенческое исследование методов извлечения русскоязычных документов для систем Retrieval-Augmented Generation.

## Цель исследования

Экспериментально сравнить следующие методы поиска документов:

- BM25;

- Dense Retrieval;

- Hybrid Retrieval.

Эксперименты проводятся на русскоязычной части набора данных Mr. TyDi.

## Структура репозитория

```text

article/    материалы и итоговая версия статьи

data/       локальные исходные и обработанные данные

docs/       план и описание исследования

results/    таблицы и графики с результатами

src/        код подготовки данных и экспериментов
