# RAG Retrieval Research

Репозиторий студенческого исследования методов извлечения русскоязычных документов для Retrieval-Augmented Generation (RAG).

На текущем этапе реализованы и проверены на русскоязычной части Mr. TyDi:

- **BM25** — классический разреженный лексический поиск;
- **Dense Retrieval** — семантический поиск на `intfloat/multilingual-e5-small` + FAISS;
- **Hybrid Retrieval** — объединение BM25 и Dense Retrieval методом weighted Reciprocal Rank Fusion (RRF);
- единая оценка retrieval-методов по Recall, MRR и nDCG;
- ablation по `nprobe` для Dense Retrieval;
- ablation по весу BM25 в Hybrid Retrieval;
- независимая финальная оценка на `test`.

## Данные

Полный русскоязычный корпус Mr. TyDi содержит **9 597 504 документа**.

Используются:

- `train`;
- `dev`;
- `test`;
- общий корпус документов;
- qrels для оценки.

`dev` использовался для выбора параметров. `test` использовался только после фиксации конфигураций.

## BM25 baseline

Конфигурация:

- `bm25s`;
- Lucene BM25;
- `k1 = 1.2`;
- `b = 0.75`;
- русский Snowball stemmer;
- документ: `title + " " + text`.

## Dense Retrieval

Основная модель:

```text
intfloat/multilingual-e5-small
```

Конфигурация:

- embedding dimension: **384**;
- документы: `passage: <title> <text>`;
- запросы: `query: <text>`;
- embeddings нормализуются;
- FAISS `IVFScalarQuantizer`;
- SQ8;
- inner product;
- `nlist = 2048`;
- обучение FAISS на 100 000 документах;
- batch size: **8**;
- полный индекс: около **3.5 GB**;
- peak RSS при построении: около **3.74 GiB**;
- скорость кодирования полного корпуса: **92.64 docs/s**.

## Hybrid Retrieval

Hybrid объединяет BM25 и Dense через weighted Reciprocal Rank Fusion:

```text
score(d) =
w_BM25 / (k + rank_BM25(d))
+
w_Dense / (k + rank_Dense(d))
```

Зафиксированная конфигурация:

- `k = 60`;
- BM25 top-100;
- Dense top-100;
- Dense `nprobe = 256`;
- `w_Dense = 1.0`;
- `w_BM25 = 0.025`;
- Hybrid top-100.

| Метод | Recall@1 | Recall@5 | Recall@10 | MRR@10 | nDCG@10 |

## Итоговый вывод

Dense Retrieval значительно превосходит BM25 на `dev` и `test`.

Hybrid Retrieval не демонстрирует однозначного превосходства над Dense:

- на `test` Hybrid немного лучше по Recall@1, MRR@10 и nDCG@10;
- Dense немного лучше по Recall@5 и Recall@10;
- различия между Dense и Hybrid малы.

Изначальная гипотеза о безусловном превосходстве Hybrid над отдельными retriever-ами не подтверждается полностью.

Для данного корпуса и выбранных реализаций основным практическим результатом является высокая эффективность Dense Retrieval на `multilingual-e5-small`, а вклад BM25 в Hybrid оказывается ограниченным.
