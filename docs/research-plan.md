# План исследования

## Рабочее название статьи

Сравнительный анализ методов извлечения русскоязычных документов для систем Retrieval-Augmented Generation.

## Цель

Экспериментально сравнить качество и производительность BM25, Dense Retrieval и Hybrid Retrieval на русскоязычной части Mr. TyDi.

## Исследовательский вопрос

Какой из рассматриваемых методов обеспечивает наиболее высокое качество извлечения релевантных русскоязычных документов при одинаковых условиях?

## Гипотеза

Гибридный поиск может превосходить отдельные retriever-ы за счёт объединения лексических и семантических сигналов.

По результатам `dev` гипотеза подтверждается только частично: Hybrid немного повышает Recall@5/10, но не превосходит Dense Retrieval по MRR@10 и nDCG@10.

## Набор данных

Русскоязычная часть Mr. TyDi:

- корпус: **9 597 504 документа**;
- train;
- dev;
- test.

Настройка параметров выполняется только на `dev`. `test` сохраняется для независимой финальной оценки.

## Методы

1. BM25.
2. Dense Retrieval на `intfloat/multilingual-e5-small`.
3. Weighted Hybrid Retrieval через RRF.

## Финальные dev-конфигурации

### BM25

- Lucene BM25;
- `k1=1.2`;
- `b=0.75`;
- русский Snowball stemmer.

### Dense

- `intfloat/multilingual-e5-small`;
- dimension 384;
- FAISS IVFScalarQuantizer + SQ8;
- `nlist=2048`;
- `nprobe=256` как основной рабочий вариант;
- `nprobe=512` как контрольная конфигурация максимального качества.

### Hybrid

- weighted RRF;
- `k=60`;
- Dense `nprobe=256`;
- `w_Dense=1.0`;
- основной Hybrid-кандидат: `w_BM25=0.025`.
