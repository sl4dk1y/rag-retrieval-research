# План исследования

## Рабочее название статьи

Сравнительный анализ методов извлечения русскоязычных документов для систем Retrieval-Augmented Generation.

## Цель

Экспериментально сравнить качество и производительность разреженного, плотного и гибридного поиска документов на русскоязычной части набора данных Mr. TyDi.

## Объект исследования

Компонент извлечения документов в системах Retrieval-Augmented Generation.

## Предмет исследования

Методы ранжирования русскоязычных документов по релевантности пользовательскому запросу.

## Исследовательский вопрос

Какой из рассматриваемых методов обеспечивает наиболее высокое качество извлечения релевантных русскоязычных документов при одинаковых условиях эксперимента?

## Гипотеза

Гибридный поиск, объединяющий результаты BM25 и плотного векторного поиска, покажет более высокое качество, чем каждый из этих методов по отдельности.

## Набор данных

Русскоязычная часть Mr. TyDi:

- общий корпус документов;

- train-запросы и разметка релевантности;

- dev-запросы и разметка релевантности;

- test-запросы и разметка релевантности.

## Сравниваемые методы

1. BM25 — разреженный лексический поиск.

2. Dense Retrieval — поиск по векторным представлениям запросов и документов.

3. Hybrid Retrieval — объединение BM25 и Dense Retrieval методом Reciprocal Rank Fusion.

## Основные метрики

- Recall@1;

- Recall@5;

- Recall@10;

- MRR@10;

- nDCG@10;

- среднее время обработки одного запроса.

4. Реализовать и оценить Dense Retrieval.

5. Реализовать и оценить Hybrid Retrieval.

6. Сравнить методы в одинаковых условиях.

## Ограничения

Исследование оценивает retrieval-компонент RAG-системы. Генерация итоговых ответов языковой моделью в основной эксперимент не входит.

## Ожидаемый результат

Количественное сравнение методов извлечения документов и практические выводы об их применимости в русскоязычных RAG-системах.
