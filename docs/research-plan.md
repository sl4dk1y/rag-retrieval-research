# План исследования

## Рабочее название статьи

Сравнительный анализ методов извлечения русскоязычных документов для систем Retrieval-Augmented Generation.

## Цель

Экспериментально сравнить качество и производительность BM25, Dense Retrieval и Hybrid Retrieval на русскоязычной части Mr. TyDi.

## Исследовательский вопрос

Какой из рассматриваемых методов обеспечивает наиболее высокое качество извлечения релевантных русскоязычных документов при одинаковых условиях эксперимента?

## Гипотеза

Hybrid Retrieval может превосходить отдельные retriever-ы за счёт объединения лексических и семантических сигналов.

По итогам исследования гипотеза подтверждается лишь частично: Hybrid даёт небольшие улучшения некоторых метрик, но не демонстрирует устойчивого превосходства над Dense Retrieval.

## Набор данных

Русскоязычная часть Mr. TyDi:

- корпус: **9 597 504 документа**;
- train;
- dev;
- test.

Параметры выбирались только по `dev`.

`test` использован один раз после фиксации конфигураций и не применялся для дополнительного tuning.

## Методы

1. BM25.
2. Dense Retrieval на `intfloat/multilingual-e5-small`.
3. Weighted Hybrid Retrieval через Reciprocal Rank Fusion.

## Финальные конфигурации

### BM25

- Lucene BM25;
- `k1=1.2`;
- `b=0.75`;
- русский Snowball stemmer;
- top-100.

### Dense

- `intfloat/multilingual-e5-small`;
- dimension 384;
- normalized embeddings;
- FAISS IVFScalarQuantizer + SQ8;
- inner product;
- `nlist=2048`;
- `nprobe=256`;
- top-100.

### Hybrid

- weighted RRF;
- `k=60`;
- Dense `nprobe=256`;
- `w_Dense=1.0`;
- `w_BM25=0.025`;
- top-100.

## Dev-результаты

| Метод | Recall@1 | Recall@5 | Recall@10 | MRR@10 | nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BM25 | 0.110545 | 0.224727 | 0.277818 | 0.158763 | 0.186966 |
| Dense, nprobe=256 | 0.394909 | 0.701818 | 0.784727 | 0.525663 | 0.588376 |
| Hybrid, w_BM25=0.025 | 0.392727 | 0.704000 | 0.787636 | 0.523740 | 0.587544 |

## Финальные test-результаты

| Метод | Recall@1 | Recall@5 | Recall@10 | MRR@10 | nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BM25 | 0.164154 | 0.296650 | 0.364824 | 0.239390 | 0.260872 |
| Dense, nprobe=256 | 0.434003 | 0.741039 | 0.810553 | 0.596679 | 0.639182 |
| Hybrid, w_BM25=0.025 | 0.434171 | 0.736013 | 0.809548 | 0.597441 | 0.639626 |

## Итоговый вывод

Dense Retrieval существенно превосходит BM25.

Hybrid даёт очень близкое к Dense качество. На `test` Hybrid немного лучше по Recall@1, MRR@10 и nDCG@10, но Dense немного лучше по Recall@5 и Recall@10.

Устойчивого превосходства Hybrid над Dense не обнаружено.
