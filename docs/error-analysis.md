# Error Analysis

## Назначение

Этот документ фиксирует качественный анализ ошибок для финального `test`-эксперимента на русскоязычной части Mr. TyDi.

Анализ выполнен после фиксации всех retrieval-параметров и не используется для дополнительного tuning.

Сравниваются:

- BM25;
- Dense Retrieval на `intfloat/multilingual-e5-small`, `nprobe=256`;
- Hybrid Retrieval через weighted RRF с `w_BM25=0.025`, `w_Dense=1.0`, `k=60`.

Cutoff анализа: **top-10**.

## Общая статистика

Всего test-запросов: **995**.

| Категория | Запросов | Доля |
| --- | ---: | ---: |
| Все три метода успешны | 373 | 37.5% |
| Все три метода не находят релевантный документ в top-10 | 146 | 14.7% |
| BM25 успешен, Dense неуспешен | 20 | 2.0% |
| Dense успешен, BM25 неуспешен | 455 | 45.7% |
| Dense успешен, Hybrid неуспешен | 1 | 0.1% |

Главный вывод: случаев, где Dense находит релевантный документ в top-10, а BM25 нет, значительно больше, чем обратных случаев: **455 против 20**.

Это показывает, что основное улучшение качества в исследовании связано именно с переходом от лексического BM25 к семантическому Dense Retrieval.

## Dense vs Hybrid

| Сравнение по reciprocal rank @10 | Запросов | Доля |
| --- | ---: | ---: |
| Hybrid лучше Dense | 58 | 5.8% |
| Dense лучше Hybrid | 48 | 4.8% |
| Результат одинаков | 889 | 89.3% |

Hybrid изменяет положение релевантного документа относительно Dense только для небольшой части запросов.

Это согласуется с итоговыми test-метриками: Hybrid и Dense показывают практически одинаковое качество, а добавление BM25 через weighted RRF даёт лишь локальные улучшения и ухудшения.

## Примеры: Hybrid улучшает Dense

Таких запросов: **58**.

Примеры:

| Query ID | Запрос | BM25 rank | Dense rank | Hybrid rank |
| --- | --- | ---: | ---: | ---: |
| 6782 | Когда родился Пер Ла́герквист? | 2 | 2 | 1 |
| 6796 | В каком году происходит действие фильма «Странная женщина»? | 1 | 3 | 2 |
| 6888 | Кто командовал войсками США (Союз) при битве на реке Булл-Ран? | — | 2 | 1 |
| 6895 | В каком городе умерла Графиня Да́рья Фёдоровна Фикельмо́н? | 1 | 3 | 2 |
| 6926 | Когда был создан сериал «Сверхъесте́ственное»? | 7 | 2 | 1 |

В ряде запросов BM25 помогает поднять релевантный документ выше в Dense ranking.

Однако улучшение обычно ограничивается одной или несколькими позициями и не приводит к большому росту агрегированных метрик.

## Примеры: Hybrid ухудшает Dense

Таких запросов: **48**.

Примеры:

| Query ID | Запрос | BM25 rank | Dense rank | Hybrid rank |
| --- | --- | ---: | ---: | ---: |
| 6772 | Какая максимальная скорость ЭД9? | — | 2 | 3 |
| 6773 | Какая протяженность улицы Рожде́ственка? | — | 1 | 2 |
| 6800 | Когда импера́торское правосла́вное палести́нское о́бщество разделилось на две независимые организации? | — | 1 | 2 |
| 6815 | Получил Оскар «Чужой» Ридли Скотта? | — | 10 | — |
| 6884 | Кто был первым императором Японии? | — | 1 | 2 |

Особенно показателен query `6815`: Dense помещает релевантный документ на 10-е место, а после RRF он оказывается за пределами top-10.

Это демонстрирует, что даже небольшой вес слабого retriever-а может иногда ухудшать хороший Dense ranking.

## Примеры общих ошибок

Все три метода не находят релевантный документ в top-10 для **146** запросов.

Примеры:

- `6763` — «Когда появился термин правово́е госуда́рство?»
- `6777` — «Когда началось Смоле́нское сраже́ние?»
- `6780` — «Когда был создан первый гобелен?»
- `6784` — «Какая длина ракеты Р-17?»
- `6829` — «Как называлось первое произведение Сэ́мюэля Бáркли Бе́ккета?»

Эта группа требует осторожной интерпретации. По текущему query-level анализу нельзя однозначно определить причину ошибки.

Возможные причины, которые следует рассматривать отдельно:

- релевантный passage сложно отличить от семантически близких кандидатов;
- формулировка запроса и формулировка релевантного passage существенно различаются;
- релевантная информация расположена в passage так, что выбранный retriever не ставит его достаточно высоко;
- ограничения приближённого FAISS-поиска;
- особенности или неполнота разметки qrels.

Последний пункт нельзя утверждать без отдельной проверки конкретных документов.

## Итог

Качественный анализ подтверждает количественные результаты исследования:

1. Dense Retrieval является главным источником прироста качества относительно BM25.
2. BM25 сохраняет небольшой объём уникально полезного лексического сигнала.
3. Weighted Hybrid Retrieval может использовать этот сигнал для улучшения части запросов.
4. Одновременно fusion способен ухудшать уже хороший Dense ranking.
5. Для большинства запросов Dense и Hybrid ведут себя одинаково.
6. Полученные результаты не подтверждают устойчивого превосходства Hybrid над сильным Dense baseline.
